# One source for the CV and the publication list

The downloadable PDF CV was maintained separately from the web CV and fell five
years behind. The HTML and PDF CV are now both rendered from `academic_cv.qmd`,
and publications live in a single BibTeX file that feeds the CV, the Research
page and the PDF. A hand-typed list was rejected because it would have to be
kept in step in three places. Only outputs with a status defined in
`GLOSSARY.md` are listed; work "in preparation" is not.
